# Jan-Innovate Hub 🚀
**Built for Smart India Hackathon (SIH)**

## 📌 Problem Statement & Team Details
* **Problem Statement ID:** SIH26043
* **Problem Statement Title:** A digital platform to crowdsource societal challenges and facilitate collaborative problem solving through universities and industry partnerships
* **Theme:** Smart Education
* **PS Category:** Software
* **Team ID:** SIH:2671
* **Team Name:** SCRIPT SQUAD

## 💡 Overview
Jan-Innovate Hub is a web-based platform that connects citizens, universities, experts, and industries to collaboratively identify and solve societal challenges. 

## ✨ Key Features
* **Problem Submission & Tracking:** Citizens can easily submit societal issues and track their resolution status (`submit.html`, `my-problems.html`).
* **AI-Assisted Analysis:** Supports automated classification, priority analysis, and duplicate detection for submitted problems.
* **Role-Based Access:** Separate authentication and dashboards for general users and administrators (`login.html`, `signup.html`, `admin.html`).

## 🛠️ Tech Stack
* **Frontend:** HTML5, CSS3, JavaScript
* **Backend:** Node.js / Express (`backend/server.js`)
* **Deployment:** Vercel

## 🌐 Live Demo
Check out the live frontend here: [https://jan-innovate-hub-frontend.vercel.app/index.html)

## 🚀 How to Run Locally
1. Clone this repository:
   ```bash
   git clone https://github.com
   ```
2. Navigate to the backend folder and install dependencies:
   ```bash
   cd backend
   npm install
   node server.js
   ```
3. Open `index.html` in your browser to view the application.
